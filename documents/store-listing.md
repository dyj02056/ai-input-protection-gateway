## 2. 상세 설명 (스토어 본문)

```text
보내기 전에 검사하고, 안전하게 마스킹하세요.

ChatGPT · Claude · Gemini 입력창에 개인정보 형식이 들어오면 바로 알려주고,
원할 때 한 번의 클릭으로 가립니다. 모든 검사는 사용자의 브라우저 안에서만
이루어지며 서버로 전송하거나 저장하지 않습니다.
(조직이 운영하는 정책 서버를 선택적으로 연결해 정책을 내려받을 수 있습니다.)

■ 이렇게 동작합니다
1. 지원 사이트의 입력창에 입력하거나 붙여넣으면 형식을 검사합니다.
2. 주민등록번호 · 전화번호 · 이메일 · API 키/토큰(JWT·개인키 포함) · 카드번호 ·
   계좌번호 · 여권번호 · 운전면허번호 · 비밀번호 형식이 감지되면
   오른쪽 위에 안내 창이 뜨고, 어떤 항목이 걸렸는지 보여줍니다.
   이 안내 창은 시간 지나 사라지지 않습니다. 필요할 때만 닫기(×) 버튼으로 닫습니다.
3. '감지 항목 마스킹' 버튼을 누르면 감지된 부분만 [전화번호] 같은
   자리표시자로 바뀝니다. 나머지 문장과 줄바꿈은 그대로 둡니다.
4. 마스킹을 잘못 눌렀다면 '실행 취소' 버튼으로 한 번 되돌릴 수 있습니다.
   (선택) 설정에서 마스킹 방식을 '세션 토큰'으로 바꾸면 [전화_1]처럼 번호가 붙은
   토큰으로 가려지고, AI 답변에 이 토큰이 나오면 이 탭의 화면에서만 원래 값으로
   보여줍니다. 같은 값은 같은 토큰입니다.
5. 파일(텍스트·CSV·Word·Excel·한글)을 첨부하면 내용을 브라우저 안에서 검사해 알려줍니다.
   (파일은 전송·저장하지 않습니다. 검사하지 못하는 파일은 그렇다고 알려줍니다.)
6. 도구 모음 아이콘 배지로 현재 입력의 위험 상태를 색으로 확인합니다.
   (초록=감지 없음, 주황=마스킹/승인 필요, 빨강=차단 권고)

■ 개인정보 보호 원칙
· 입력 내용을 외부로 전송하지 않습니다. 기본 설정에서는 네트워크 요청이 없습니다.
· (선택) 설정에서 조직 정책 서버를 연결하면 정책 표만 내려받아 브라우저 안에서 판정합니다.
  입력한 글·파일은 서버로 보내지 않습니다. 기본은 API 키와 정책 요청뿐이고, 설정의 별도 동의 스위치를
  직접 켠 경우에만 감지 이벤트(시각·조치·범주 ID)를 서버로 보냅니다(기본 꺼짐).
· (선택) 별도 동의 스위치를 켜면, 승인 검토 판정에서 사용자가 "승인 요청 보내기"를 누를 때에만
  감지된 항목 종류·업무 목적·직접 쓴 짧은 사유를 서버로 보내 관리자의 승인을 받습니다(기본 꺼짐).
· 일치한 원문 문자열을 저장하거나 기록하지 않습니다.
· 감사 기록을 켜도 판정 이름·범주 ID·시각만 남으며, 최근 20건을 넘지 않습니다.
· 검사 결과는 PDP(정책 결정점)와 공유하는 범주 ID(예: phone_number)뿐입니다.
· 세션 토큰의 대응표(토큰↔원래 값)는 이 탭의 메모리에만 있고, 저장하거나 전송하지
  않으며 새로고침하면 사라집니다. 복원은 화면에 보여주기만 하며, 설정에서 끌 수 있습니다.
· 첨부파일은 이 브라우저 안에서만 읽어 검사하며 파일 내용은 저장·전송하지 않습니다.
  결과에는 파일 이름과 감지된 항목의 종류·개수만 쓰고, 감사 기록에는 파일 이름도 남기지 않습니다.
· 설정도 브라우저 로컬에만 저장됩니다. 감지에서 빼고 싶은 값(회사 대표번호 등)을
  사용자가 직접 적어 두는 '허용 목록'도 이 브라우저에만 저장되며 전송되지 않습니다.

■ 자동으로 막지 않습니다 (기본값)
· 기본 설정에서는 아무것도 차단하지 않고 안내만 합니다.
· 설정에서 '전송 차단'을 직접 켜야 정책 판정이 BLOCK인 값을 실어 보낼 때
  첫 전송 시도를 중단합니다. 5초 안에 한 번 더 누르면 그대로 전송됩니다.
· '승인 확인 단계'도 꺼져 있으며, 켜는 경우에만 승인 검토 대상에서 확인을 요구합니다.
· 스위치를 끄면 즉시 원래대로 돌아갑니다.

■ 지금 버전의 한계 (먼저 알려드립니다)
· 정규식 기반이라 일부 형식만 찾습니다. 감지되지 않았다고 안전한 것은 아닙니다.
· 계좌·여권·면허·비밀번호는 오탐을 줄이려고 앞에 "계좌", "여권" 같은 문맥 단어가
  있을 때만 찾습니다. 이름과 주소는 아직 찾지 못합니다.
· 눈에 보이지 않는 문자, 한글로 쓴 숫자, URL·Base64로 감싼 값도 찾지만, 이런 값은
  위치를 특정할 수 없어 자동으로 가리지 않고 직접 수정하도록 안내합니다.
· 판정은 브라우저 안의 정책 엔진이 합니다. 조직 정책 서버를 연결하면 그 서버의 정책 표를 쓰고,
  연결하지 않으면 내장 기본 정책을 씁니다. 서버가 막아 주는 것이 아니라 정책만 내려받는 것입니다.
· 세션 토큰 복원은 이 탭의 화면에서만 보입니다. 복원된 값은 화면에 있는 동안 해당
  사이트의 스크립트가 읽을 수 있는 상태가 되므로, 민감한 값이라면 복원을 끄세요.
  내가 보낸 메시지는 복원하지 않으며, 새로고침하면 복원 정보가 사라집니다.
· 마스킹을 되돌리는 '실행 취소'는 직전 한 번만 가능합니다.
· 파일 검사는 텍스트·CSV·Word(.docx)·Excel(.xlsx)·한글(.hwpx)만 내용을 읽습니다. PDF·이미지·
  구형 형식(.doc·.xls·.hwp)·압축 파일·암호가 걸린 파일은 내용을 검사하지 못하며, 그렇다고 알려줍니다.
  파일 안의 값을 가려 주지는 못합니다. 사이트가 선택 즉시 업로드를 시작할 수 있어 업로드 자체는 막지 못합니다.
· 승인 워크플로와 관리 화면은 다음 버전입니다.

■ 사용 팁
처음 사용할 때는 도구 모음 아이콘 → '시작 가이드'에서 60초 안내를 확인하세요.
설정에서 필요 없는 탐지 항목을 끌 수 있고, 안내창 위치와 자동 닫힘도 바꿀 수 있습니다.
```

## 3. 권한 사용 사유 (심사 답변용)

| 권한 | 사유 |
|---|---|
| `storage` | 탐지 항목 on/off 설정을 사용자의 브라우저 로컬에만 저장합니다. |
| 호스트 `https://chatgpt.com/*`, `https://chat.openai.com/*`, `https://claude.ai/*`, `https://gemini.google.com/*` | 위 4개 주소의 입력창에만 검사·마스킹 안내를 표시합니다. 다른 사이트에 접근하지 않습니다. |
| 선택 호스트 `optional_host_permissions` (`https://*/*`, `http://localhost/*`, `http://127.0.0.1/*`) | **설치할 때는 요구하지 않습니다.** 사용자가 설정에서 조직의 정책 서버를 직접 연결할 때에만 브라우저가 그 서버 주소 하나에 대한 접근을 묻습니다. 정책(범주별 조치 표)을 내려받는 데만 쓰고, 입력한 내용은 보내지 않습니다. 서버 주소를 미리 알 수 없어 `https://*/*`로 선언했으며 연결을 끊으면 권한을 돌려줍니다. |

- `tabs` 권한은 요청하지 않습니다. 도구 모음 팝업은 `chrome.tabs.query`의 제한된 정보만 사용하며 탭 주소를 읽을 수 없으면 "지원 사이트가 아님"으로 표시합니다.
- 원격 코드를 실행하지 않습니다. 모든 JavaScript는 패키지에 포함되어 있습니다.

## 4. 데이터 사용 신고 (Data usage)

| 질문 | 답 |
|---|---|
| 사용자 데이터를 수집·전송합니까? | 기본은 아니오. 사용자가 조직 서버를 연결하고 "감사 이벤트 전송" 스위치를 직접 켠 경우에만 감지 이벤트(시각·조치·범주 ID·정책 버전)를 그 서버로 전송합니다. "승인 요청" 스위치를 직접 켠 경우에만, 사용자가 안내창에서 요청 버튼을 눌렀을 때 감지된 범주 ID·업무 목적(선택지)·사용자가 쓴 짧은 사유(100자 이내)를 그 서버로 전송합니다. 입력 텍스트·파일·사이트 주소는 어떤 경우에도 보내지 않으며 개발자에게는 전송되지 않습니다. |
| 개인 식별 정보 / 인증 정보 / 재무 정보 | 수집하지 않음 |
| 위치 / 검색 기록 / 방문 기록 | 수집하지 않음 |
| 웹사이트 콘텐츠 | 사용자가 입력한 텍스트를 검사 목적으로 로컬에서 읽지만, 저장·전송하지 않음 |
| 사용자 활동(클릭 등) | 수집하지 않음 |
| 제3자와 공유 / 판매 | 해당 없음 |
| 위치·콘텐츠와 무관한 광고 목적 사용 | 없음 |
| 인증 정보를 제3자에게 판매 | 없음 |

- 위 신고는 Chrome 웹 스토어 개발자 프로그램 정책의 "제한적 사용(Limited Use)" 요건과 일치합니다.
- 설정 화면의 '무시할 값(허용 목록)'은 사용자가 직접 입력한 설정값이며 `chrome.storage.local`에만 저장되고 외부로 전송되지 않습니다. 입력창에서 읽은 내용을 저장하는 것이 아닙니다.
- 선택 항목인 감사 기록은 사용자가 켠 경우에만 동작합니다. 켜더라도 판정 이름·범주 ID·시각만 `chrome.storage.local`에 남기고 최근 20건을 넘지 않으며, 일치한 원문 문자열은 저장하지 않습니다. 설정 화면의 "로컬 기록 전체 삭제"로 지울 수 있습니다.
- 개인정보 처리방침 전문: https://dyj02056.github.io/ai-input-protection-gateway/privacy.html

## 5. 스토어 등록 이미지 (직접 캡처 필요)

스토어는 스크린샷이 1장 이상 필요합니다(1280×800 또는 640×400). 아래 순서로 촬영을 권장합니다.

| 순서 | 장면 | 캡처 대상 |
|---|---|---|
| 1 | 홈 화면 | https://dyj02056.github.io/ai-input-protection-gateway/ |
| 2 | 로컬 데모에서 가짜 5줄 검사 결과 | https://dyj02056.github.io/ai-input-protection-gateway/demo.html |
| 3 | 실제 입력창의 감지 안내 + 마스킹 버튼 | ChatGPT에 가짜 문구 입력 (전송 금지) |
| 4 | 마스킹 적용 결과와 실행 취소 버튼 | 위 상태에서 마스킹 버튼 클릭 후 |
| 5 | 도구 모음 팝업 + 배지 | 확장 아이콘 클릭 |
| 6 | 설정 화면(안내 표시·실행 취소·감사 기록) | 팝업 → 설정 |
| 7 | 전송 차단이 꺼져 있는 상태 | 설정의 "전송 보호" 카드 |

- 촬영 시 실제 개인정보·키를 쓰지 말고 가짜 문구만 사용합니다.
- 콘텐츠가 과장되지 않도록 "기본값으로는 자동으로 막지 않는다"는 안내 문구가 보이는 화면을 포함합니다.

## 6. 심사 시 확인 방법

1. `dist/ai-input-protection-gateway-1.7.0.zip`의 압축을 풀고, 풀린 폴더를 `chrome://extensions` → 개발자 모드 → "압축해제된 확장 프로그램을 로드"로 설치합니다. (소스 저장소에서 직접 설치하려면 `npm install` → `npm run build` 후 `dist-ext/` 폴더를 로드합니다. 소스 폴더 `browser-extension/`는 빌드 전 파일이라 로드되지 않습니다.)
2. 설치 직후 "60초 시작하기" 탭이 열립니다.
3. ChatGPT 또는 Claude에 아래 가짜 문구를 붙여넣습니다(전송하지 않음).

   ```text
   가짜 주민번호 000000-1000000
   가짜 전화번호 010-0000-0000
   가짜 이메일 test.user@example.com
   가짜 키 sk-TESTTESTTESTTESTTEST
   그대로 남아야 할 문장
   ```

4. 안내 창이 시간 지나 사라지지 않고 남아 있는지 확인합니다(닫기 × 버튼으로 닫을 수 있습니다).
5. "감지 항목 마스킹" 버튼을 누르면 네 값만 `[주민등록번호]`, `[전화번호]`, `[이메일]`, `[API 키/토큰]`으로 바뀌고 마지막 문장과 5줄 구조가 유지됩니다. 줄 사이에 빈 줄이 생기지 않아야 합니다.
6. "실행 취소"를 누르면 마스킹 전 문장으로 돌아갑니다.
   (새 범주 확인) 다음 가짜 문구도 붙여넣어 보세요. 모두 공개 테스트용이거나 가짜 값입니다.

   ```text
   가짜 카드번호 4111 1111 1111 1111
   가짜 계좌번호 110-123-456789
   가짜 여권번호 M12345678
   가짜 비밀번호: abc12345
   ```

   카드번호·계좌번호·여권번호·비밀번호만 `[카드번호]`, `[계좌번호]`, `[여권번호]`, `[비밀번호]`로 바뀌고 "가짜 …" 글자와 `비밀번호:`는 남습니다.
6-2. (파일) 메모장에 `연락처 010-0000-0000`을 적어 `.txt`로 저장해 AI 사이트에 첨부하면(전송하지 않음)
   "첨부파일 검사 결과" 안내가 뜨고 "전화번호 형식 감지"가 표시됩니다. 설정에서 "첨부파일 전송 차단"과
   "로컬 정책 적용"을 켜면 보내기 첫 시도가 중단되고 5초 안에 다시 누르면 전송됩니다.
7. 설정에서 "이메일 형식"을 끄고 같은 문구를 다시 붙여넣으면 이메일은 안내에서 제외됩니다. 설정에서 안내창 위치를 "왼쪽 아래"로 바꾸면 안내를 닫았다가 다시 띄워도 그 위치가 유지됩니다.
8. 설정에서 "전송 차단"을 켠 뒤 API 키가 들어 있는 상태에서 보내기를 누르면 첫 시도가 중단되고, 5초 안에 다시 누르면 전송됩니다. 꺼 두면 아무것도 막히지 않습니다.
9. 소스 저장소에서 `npm test`(빌드 후 vitest 958개), `py tools/dom_test.py`(65개, 헤드리스 Chrome, `npm run build` 선행), `py tools/policy_parity.py`(40개 대조), `py -m unittest discover -s gateway-core/pdp -p "test_*.py"`(9개)로 회귀를 확인할 수 있습니다. 서버 연동은 `py tools/server.py setup` 후 `py tools/server.py test`(84개)와 `py tools/server.py e2e`(실제 서버와 확장 코드 13개)로 확인합니다. 서버를 연결하지 않으면 확장은 네트워크 요청을 하지 않습니다.
