일부 문자열 패턴 검사 — Chrome에서 확인 필요

현재 동작

대상 사이트의 텍스트 입력·붙여넣기 뒤 입력창 내용을 로컬 정규식으로 검사합니다. 주민등록번호·전화번호 형식과 일부 API 키/토큰 형식만 살펴보며, 알림에는 일치한 문자열 대신 유형 이름만 표시합니다.

이 기능은 형식만 확인하는 초기 실험이라 오탐·누락이 있을 수 있습니다. 개인정보 여부를 확정하거나 입력을 마스킹·차단하지 않습니다. 확장 프로그램은 검사 내용을 저장하거나 서버로 보내지 않지만, 입력창은 AI 사이트 페이지 안에 있으므로 사이트 자체의 처리는 별개입니다. 민감정보 대신 가짜 테스트 문구를 사용하고 전송하지 마세요.
