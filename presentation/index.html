확장이 입력을 가로채 검사하고 정책 표로 판정합니다. 서버는 정책을 내려주고, 사용자가 별도로 동의한 감사 이벤트와 승인 요청만 받으며, 관리 콘솔에서 승인 처리와 정책 변경을 합니다. 서버를 연결하지 않으면 네트워크 요청은 없습니다.

확장은 TypeScript로 쓰고 Vite로 번들하며, 설정과 팝업 화면은 React, 안내창은 가벼운 Preact로 만들었습니다. 서버는 Python FastAPI, 공개 사이트는 Astro, 테스트는 Vitest와 unittest를 씁니다.

입력한 글과 파일은 브라우저 밖으로 나가지 않습니다. 서버로 가는 것은 범주 ID, 조치, 시각, 정책 버전과 승인 요청 시의 목적과 짧은 사유뿐이고 모두 사용자가 별도로 동의해야 합니다. 서버는 API 키의 해시만 가지며, 감사 로그는 해시 체인으로 변조를 알아볼 수 있습니다.

승인 필요 판정을 받은 글은 전송이 멈추고, 사용자가 업무 목적을 골라 요청합니다. 관리자가 승인하면 딱 한 번만 통과합니다. 승인 뒤 글자를 하나라도 바꾸면 무효이고, 같은 승인으로 두 번 보낼 수 없으며, 서버가 응답하지 않아도 승인 없이는 통과하지 않습니다. 내용 비교는 탭 메모리 안에서만 합니다.

관리 콘솔은 서버가 내려주는 정적 화면으로, 관리자 키로 로그인합니다. 승인함에서 요청을 건별로 승인하거나 거절하고, 정책 탭에서 새 버전을 만들거나 이전 버전으로 되돌립니다. 감사 로그와 관리 기록은 체인 검증으로 조작 여부를 확인합니다. 화면의 데이터는 모두 텍스트로만 그려 악성 입력이 실행되지 않습니다.
