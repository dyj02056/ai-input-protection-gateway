# 발표자료

프로젝트 소개 발표자료(22장, 16:9 · 1280×720)입니다.

| 파일 | 설명 |
|---|---|
| `index.html` | 발표용 슬라이드. 브라우저로 열어 발표합니다(인터넷 연결 필요: 아이콘 글꼴을 CDN에서 읽음) |
| `slides.pdf` | 제출·인쇄용 PDF (`build_pdf.py`가 `index.html`에서 만듭니다) |
| `build_pdf.py` | 헤드리스 Chrome/Edge로 PDF 내보내기 |
| `check_slides.py` | 규칙 검사: 모든 텍스트 10자 이하, 문장형 없음, 글자 크기 18px 이상 |

## 발표할 때 (index.html)

| 키 | 동작 |
|---|---|
| `→` `Space` `Enter` / 화면 오른쪽 클릭 | 다음 슬라이드 |
| `←` `Backspace` / 화면 왼쪽 클릭 | 이전 슬라이드 |
| `F` | 전체 화면 |
| `N` | 발표자 노트 보기/숨기기 (슬라이드 밖 아래쪽 패널) |
| `Home` / `End` | 처음 / 끝 |

주소 끝의 `#12`처럼 쓰면 12번 슬라이드로 바로 엽니다.

## 구성

타이틀 → 목차 → 5개 단원(각각 도입부 + 내용 2~3장) → Q&A → 감사 인사

1. 프로젝트 개요 · 2. 핵심 기능 · 3. 시스템 구조 · 4. 서버·승인 · 5. 검증·계획

## 고치고 다시 만들 때

```bash
py presentation/check_slides.py   # 규칙 검사 (통과해야 함)
py presentation/build_pdf.py      # slides.pdf 다시 만들기
```

- 슬라이드의 모든 글은 **10자 이하 키워드**여야 합니다. 설명 문장은 `<aside class="notes">`(발표자 노트)에만 쓰세요. 노트는 슬라이드 화면과 PDF에 나오지 않습니다.
- 테스트 수치(964·84·65·13·40/40)는 `README.md`의 현재 결과와 맞춰 두었습니다. 테스트가 늘면 19번 슬라이드를 고치세요.
