0. 요약

외부 AI 입력 직전 검사 → ALLOW/MASK/APPROVAL/BLOCK → 원문 없이 감사. 현 구현은 로컬 4종+NFKC+조치안내+수동마스킹, PDP 데모 판정. 자동 차단·서버 연동 미구현.

1. 개요

무통제 입력, 정규식 한계, 차단 역효과, RAG·도구 신경로, 인력 0~2명. 1일 적용·정책팩·마스킹복원·원문없는 재현.

2. 위협·정책

전체평가후 최제한, exception만 완화, 무매칭 0건 ALLOW/있음 APPROVAL, 변환후 재판정. 데모: 주민/전화/이메일 MASK, 키 BLOCK.

4. UX

배지→미리보기→승인→대안→복원. 본인 로컬표시, 승인자 원문비노출. 관찰→안내→강제.

5. 보안

원문미저장, TTL2h, 감사1년, 해시체인·가명ID. inspect 범주ID만 반환.
