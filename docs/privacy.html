개인정보 처리방침

대상: Chrome 확장 프로그램 AI 입력정보 보호 게이트웨이 (버전 1.7.0)
시행일: 2026-10-01 · 최종 개정일: 2026-10-02

한 줄 요약

이 확장 프로그램은 사용자의 입력 내용을 외부 서버로 전송하지 않고, 개발자를 포함한 누구에게도 수집·열람·저장하지 않습니다. 모든 검사는 사용자의 브라우저 안에서만 실행됩니다. 기본 설정에서는 네트워크 요청이 전혀 없고, 사용자가 직접 조직 정책 서버를 연결한 경우에만 정책을 내려받는 요청을, 별도 동의 스위치를 켠 경우에만 감사 이벤트(범주 ID·조치·시각)와 관리자 승인 요청(범주 ID·업무 목적·직접 쓴 짧은 사유)을 그 서버로 보냅니다(6-1항).

1. 수집하지 않는 정보

항목처리 여부
이름·이메일·전화번호 등 개인 식별 정보수집하지 않음
AI 사이트 입력창에 사용자가 입력·붙여넣기한 텍스트전송·저장하지 않음 (로컬 검사 후 즉시 폐기)
열람 기록·방문 URL·검색어수집하지 않음
계정 정보·결제 정보수집하지 않음
분석 도구(애널리틱스)·광고 식별자사용하지 않음
원격 코드 로딩없음 (모든 코드는 패키지에 포함)

2. 브라우저 안에서만 하는 일

확장 프로그램은 아래 사이트의 입력창에서만 동작하며, 입력된 텍스트를 브라우저 메모리에서 정규식으로 검사합니다. 검사 결과는 범주 ID(예: phone_number)이며, 원문이나 일치한 문자열은 어디에도 기록되지 않습니다.

  • https://chatgpt.com/*, https://chat.openai.com/*
  • https://claude.ai/*
  • https://gemini.google.com/*

일부 값(URL 인코딩이나 Base64로 감싼 문자열, 눈에 보이지 않는 문자 등)은 검사를 위해 브라우저 메모리에서 풀어 보지만, 풀어낸 내용도 저장하거나 전송하지 않습니다.

첨부파일(파일 선택·드롭·붙여넣기)은 이 브라우저 안에서만 읽어 검사합니다. 파일 내용은 저장하거나 전송하지 않고, 검사가 끝나면 남기지 않습니다. 화면에 표시되는 결과에는 파일 이름과 감지된 항목의 종류·개수만 있으며, 감사 기록(켠 경우)에는 파일 이름도 남기지 않습니다. 설정에서 이 검사를 끌 수 있습니다.

설정에서 마스킹 방식을 세션 토큰으로 고르면, 가린 값과 토큰([전화_1])의 대응표를 그 탭의 브라우저 메모리에만 두고 AI 답변에 나온 토큰을 화면에서만 원래 값으로 바꿔 보여줍니다. 이 대응표는 저장하거나 전송하지 않으며 탭을 새로고침하거나 닫으면 사라집니다. 다만 복원된 값은 화면에 있는 동안 해당 사이트의 스크립트가 읽을 수 있는 상태가 되므로, 원치 않으면 설정에서 복원 표시를 끌 수 있습니다(토큰이 그대로 보입니다). 내가 보낸 메시지는 복원하지 않습니다.

마스킹은 사용자가 안내 창의 버튼을 직접 눌렀을 때만 적용되며, 입력 내용을 자동으로 전송하거나 차단하지 않습니다.

3. 브라우저에 저장되는 정보

저장 항목저장 위치목적
탐지 항목 on/off 설정 (9종)chrome.storage.local사용자가 끈 범주를 검사·마스킹에서 제외
무시할 값 목록(허용 목록) — 사용자가 직접 적은 경우에만chrome.storage.local회사 대표번호처럼 사용자가 감지에서 빼려고 설정 화면에 직접 적은 값. 입력창에서 읽은 내용이 아니라 사용자가 적은 설정값이며, 설정 화면에 그대로 보입니다
기능 스위치와 마스킹 방식 설정 (안내 계속 표시, 실행 취소, 감사 기록, 전송 차단, 세션 토큰·복원 표시 등)chrome.storage.local사용자가 고른 화면 표시 방식과 차단 수준을 저장

이 값은 사용자의 브라우저 프로필에만 남고, 개발자 서버나 제3자에게 전송·동기화되지 않습니다. 설정 페이지의 “로컬 기록 전체 삭제” 버튼 또는 확장 프로그램 제거로 언제든 삭제할 수 있습니다.

감사 기록에도 일치한 원문 문자열은 저장하지 않습니다. 저장되는 항목은 `BLOCK`·`MASK` 같은 조치 이름, `phone_number` 같은 범주 ID, 그리고 시각뿐입니다. 입력문장, 발견된 문자열, 몇 번째 항목인지와 같은 위치 정보는 남지 않으며, 범주만으로는 원래 내용을 복원할 수 없습니다.

4. 요청하는 권한과 이유

권한사용 이유
storage위 3항의 설정값을 브라우저 로컬에 저장하기 위해서만 사용합니다.
선택 호스트 권한 (optional_host_permissions) — 설치 시 요구하지 않음사용자가 설정에서 조직 정책 서버를 연결할 때에만, 그 서버 주소 하나에 대한 접근을 브라우저가 묻습니다. 정책을 내려받는 데만 쓰며, 연결을 끊으면 돌려줍니다.
호스트 권한 (ChatGPT·Claude·Gemini 4개 주소)해당 사이트의 입력창에 검사·마스킹 안내를 표시하기 위해서만 사용합니다. 그 외 사이트에는 접근하지 않습니다.

브라우저 방문 기록(tabs) 권한은 요청하지 않습니다.

5. 제3자 제공 및 국외 이전

수집 자체를 하지 않으므로 제3자 제공, 판매, 국외 이전이 발생하지 않습니다. 확장 프로그램은 기본 설정에서 네트워크 요청을 보내지 않으며, 사용자가 연결한 경우의 요청은 10항의 범위로 제한됩니다.

6. 사용자가 입력한 내용에 대한 안내

이 확장 프로그램은 검사를 위해 입력창의 텍스트를 읽습니다. 다만 그 내용은 브라우저 메모리에서 검사에만 사용되고 저장·전송되지 않습니다. 확장 프로그램을 사용하더라도, 사용자가 전송 버튼을 누르면 입력 내용은 해당 AI 서비스 제공자에게 전송됩니다. 이때의 처리는 각 AI 서비스의 개인정보 처리방침을 따릅니다.

1.1.0부터 설정에 전송 차단 스위치가 추가되었지만 기본값은 꺼짐입니다. 사용자가 직접 켜면 로컬 정책 판정이 BLOCK인 값을 실어 보낼 때 첫 전송 시도를 중단할 뿐이며, 5초 안에 한 번 더 누르면 그대로 전송됩니다. 끄면 즉시 원래대로 동작합니다. 확장은 서버에 알리지 않고 브라우저 안에서만 판단합니다.

6-1. 조직 정책 서버 연결 (선택, 기본 꺼짐)

조직(회사·학교)이 정책 서버를 운영하는 경우에만, 사용자가 설정 화면에서 서버 주소와 API 키를 입력해 연결할 수 있습니다. 연결하면 확장은 서버에서 정책 표(범주별 조치와 대량 기준)를 내려받아 브라우저 안에서 판정합니다.

  • 서버로 보내는 것: API 키(인증 헤더)와 이전 정책의 식별값(ETag)뿐입니다. 쿠키·방문 기록·계정 정보는 보내지 않습니다.
  • 서버로 보내지 않는 것: 입력한 텍스트, 첨부파일(이름 포함), 사이트 주소, 감지 건수. 감지된 범주, 감사 이벤트, 승인 요청은 아래 별도 동의 스위치를 켠 경우에만 보냅니다.
  • 감사 이벤트 전송 (별도 동의, 기본 꺼짐): 서버를 연결한 뒤 설정에서 “감사 이벤트를 조직 서버로 전송”을 직접 켜면, 감지될 때마다 무작위 이벤트 ID, 발생 시각, 조치 이름(BLOCK 등), 범주 ID(예: phone_number), 입력/파일 구분, 정책 버전이 서버로 전송됩니다. 서버는 이를 변조를 알아볼 수 있는 기록(해시 체인)으로 쌓으므로, 서버를 운영하는 조직은 어떤 호출자 키로 언제 어떤 범주가 감지되어 어떤 조치가 나왔는지를 볼 수 있습니다. 서버 연결만으로는 켜지지 않으며, 끄거나 연결을 끊으면 보내지 못해 쌓여 있던 이벤트도 보내지 않고 지웁니다. 서버로 간 기록은 이 확장에서 지울 수 없고 서버 운영 조직이 관리합니다.
  • 관리자 승인 요청 (별도 동의, 기본 꺼짐): 서버를 연결하고 설정의 “로컬 정책 적용”·“승인 확인 단계”를 켠 뒤 “승인 검토 판정 시 조직 서버로 승인 요청”을 직접 켜면, 승인 검토 판정에서 전송이 멈추고 사용자가 안내창에서 “승인 요청 보내기”를 누를 때에만 감지된 항목의 범주 ID, 업무 목적(고정 선택지 중 하나), 사용자가 직접 쓴 사유(선택, 100자 이내)가 서버로 전송됩니다. 이후 승인 결과를 확인하려고 서버에 요청 번호로 상태를 묻고, 승인되면 “사용”을 알립니다. 사유는 서버 운영 조직의 관리자 화면에 그대로 보이므로 이름·전화번호 같은 개인정보를 쓰지 마세요. 입력한 글, 파일, 사이트 주소는 보내지 않습니다. 승인은 한 번만 쓸 수 있고, 요청한 뒤 입력 내용이 바뀌었는지는 이 탭의 메모리 안에서만 비교합니다(비교용 값은 서버로 보내지 않고 저장하지 않으며 탭을 닫거나 새로고침하면 사라집니다). 서버 연결만으로는 켜지지 않고, 연결을 끊으면 동의도 함께 꺼집니다.
  • 서버 주소는 https만 쓸 수 있습니다(개발용 localhost 제외). 연결 버튼을 누르면 브라우저가 그 주소에 대한 접근 허용을 물어봅니다.
  • 서버를 운영하는 조직은 요청 시각과 호출한 키 이름을 알 수 있습니다. 이 서버는 개발자가 운영하지 않으며, 개발자는 이 정보를 받지 않습니다.
  • 설정에서 “연결 끊기”를 누르면 저장된 주소·API 키·정책이 지워지고 접근 권한도 돌려줍니다.

7. 아동의 개인정보

확장 프로그램은 아동을 대상으로 하지 않으며, 연령과 무관하게 개인정보를 수집하지 않습니다.

8. 방침의 변경

방침이 바뀌면 이 페이지의 개정일을 갱신합니다. 수집 범위가 늘어나는 변경은 하지 않는 것을 원칙으로 합니다.
